# Arulmurugan & Yuvasri — Wedding Invitation

A responsive HTML/CSS/JavaScript wedding invitation inspired by the uploaded reference recording.

## Included
- Desktop + mobile responsive layout
- Fixed Tamil/English translation button
- Countdown to 17 September 2026, 7:00 AM IST
- Wedding and reception details
- Google Maps buttons
- Mobile hamburger navigation
- Decorative temple/wedding styling
- Lightweight generated "music" bell toggle using Web Audio (no external audio file)
- ChatGPT-generated concept image included under `assets/`

## Run
Open `index.html` in a browser. No build tool is required.

## Customize
- Edit all wording in `index.html` and `script.js`.
- Replace `assets/hero-bg.jpg` with your own wedding/temple photo if desired.
- Update the two Google Maps search links in `index.html`.
